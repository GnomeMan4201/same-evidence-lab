# Blind labeling: 24 short cases

For each case, using **only** the listed evidence, write which explanations the evidence does **not** rule out.

- If exactly one survives, write that letter (e.g. `B`).
- If two or more survive, write all of them (e.g. `A, C`).
- "Less likely" is not "ruled out". Only count something as ruled out if the evidence actually excludes it.
- Please label alone and don't look at anyone else's answers.

Reply with one line per case, like `case-1a2b3c: B`. A short note on any case you think is badly written is welcome.
